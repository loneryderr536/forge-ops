# Forge-ops

Evidence-based, reviewed coding agent for VS Code, powered by TrueForge. Every edit is shown as a diff you accept or reject hunk by hunk.

Commands: `Forge-ops: New Task`, `Inline Edit` (Cmd/Ctrl+Alt+K), `Stop Run`, `Undo Last Run`, `Select Model`.
Settings: `forge-ops.trueforgeUrl`, `forge-ops.models`.
